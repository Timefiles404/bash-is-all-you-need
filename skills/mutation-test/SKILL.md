# 给这个仓库的测试套件做变异测试

不会失败的测试套件一文不值，而套件跑绿了，并不能证明它会失败。这里每个
测试文件都得过这条验收线。

## 流程

每个变异都这么走：

1. 把源文件逐字节复制到仓库外的临时位置。
2. 只做一处变异，不多不少。
3. **先**跑 `go vet ./stages/<stage>/`。编译不过的变异什么也证明不了。
   那不叫被抓住，那叫写废了。把它改到能编译（整块删掉会留下没人用的
   变量，那就写成 `if false && x`）。
4. 跑 `go test ./stages/<stage>/`。它**必须挂**，而且要记下是哪条测试
   抓住的。
5. 从字节副本还原，再用 `cmp` 确认还原得一个字节不差。

变异活下来，就是缺了一条测试。补上。

## 到哪儿都值得试的变异

- 翻边界：`<=` 改成 `<`，`>=` 改成 `>`。
- 复合条件里砍掉一条子句。
- 代码返回最后一个元素的地方，改成返回第一个；反过来也试。
- 删掉一处错误检查，让它顺着正常路径往下走。
- 把排序倒过来，或者干脆把排序去掉。
- 把算出来的值换成看着合理的常量。
- 本该遍历全部元素的循环，让它漏掉一个。

## 这个代码库特有的变异

- **记账**：把 `Usage.Input` 改成等于 `prompt_tokens`，而不是
  `prompt_tokens - cached_tokens`。冷请求上根本看不出来，所以只测
  冷调用的套件抓不到它。
- **切点**：`canCutBefore` 里有两个检查，删掉其中一个。只剩一个照样能
  过——只要那次对话的切点碰巧落在安全的位置。
- **字节保真**：把 `Block.Args` 过一遍 `map[string]any` 再编码回去。
  值相等，字节动了。
- **显示宽度**：让宽字符报成 1 列。

## 报告

交一张表：变异、能不能编译、抓住还是活下来、哪条测试抓住的。哪些变异是
你为了让它编译才改写的，单独点出来；哪些变异只有一条测试抓得住，也点
出来——那条测试现在是承重墙，得在注释里写明这件事。
